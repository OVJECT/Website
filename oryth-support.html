Oryth Support

Oryth is a high-fidelity macOS music player focused on local audio playback, DAC-aware output, and lightweight analog color controls.

Common troubleshooting

  • If Oryth cannot access a music folder, remove and re-add the folder using the in-app import flow.
  • If playback uses the wrong output device, reconnect the DAC and select it again in Oryth.
  • If macOS permission prompts do not appear, reset the related permission in System Settings and relaunch Oryth.

Privacy

Oryth is designed for local playback. It does not require an account to play local files. Network access is used only for user-requested online content features.
